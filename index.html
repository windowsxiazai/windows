关于

  • 互联网中的 MSDN 资源发布站点不计其数，但大部分只提供下载地址和文件名称，并未细化。
  • 以 Windows 操作系统来说，一个镜像文件可能包含多个版本，且镜像文件名称为英文，对英文不好的用户来说选择极为不便。本站的目的就是把镜像文件中的所有版本列出，并将镜像文件名以中文显示。
  • 本站所有资源均下载到本地进行了版本识别、SHA-1 和 MD5 校验，基本可保证无误。

MSDN 与系统版本说明

  • MSDN 的全称为 Microsoft Developer Network（微软开发者网络），真正意义上的 MSDN 指 MSDN Subscription（MSDN 订阅）——一种付费订阅服务，可将微软几乎所有软件以开发为目的使用。
  • Windows 操作系统主要区分为 Ghost 系统和 MSDN 系统：Ghost 系统由个人或团队修改官方原版而成，可能不稳定、存在后门、捆绑第三方软件；MSDN 系统为官方原版，安装后默认未激活，需使用有效的正版密钥激活。
  • 《企业版》《教育版》《商业版》一般属于批量授权版（大客户版），缩写 VOL 或 VL；《消费者版本》《多版本》中不带 VOL / VL 字样的一般属于零售版。
